# Le Berceau des Ambitions — site de l'association (préproduction)

Site vitrine statique : `index.html` + `assets/`. Conserver les deux ensemble.
Fichiers de mise en ligne : `404.html`, `robots.txt`, `sitemap.xml` (à placer à la racine de l'hébergement).

## À savoir
- Tout texte en rouge italique entre crochets `[à compléter]` est une information à fournir par l'association (lieu, horaires, tarif, public, téléphone, RNA, hébergeur…).
- Soutien scolaire et accompagnement administratif et social : gratuits « pour le moment ».
- Formulaire : toujours en `mailto:` ; à remplacer par un service de formulaire hébergé pour la production.
- Ne pas mentionner de réduction fiscale pour les dons sans vérification.
- Visuel du pôle associatif : `assets/pole-associatif.png`.
- Le domaine `le-berceau-des-ambitions.fr` (balises canonical, Open Graph, JSON-LD, robots.txt, sitemap.xml) est à confirmer avant publication.
